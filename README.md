# CalSnap 📸

แอปถ่ายรูปอาหารแล้วให้ AI (Google Gemini) ประเมินชื่อเมนูและแคลอรี่ พร้อมสรุปแคลอรี่ที่ได้รับในแต่ละวัน

- HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร
- เก็บข้อมูลและ API Key ใน Local Storage ของเบราว์เซอร์ผู้ใช้เท่านั้น
- ธีมสีฟ้า ใช้ได้ทั้งมือถือและคอมพิวเตอร์

## วิธีใช้
1. เปิด `index.html` (หรือเปิดผ่าน GitHub Pages)
2. กด ⚙️ แล้วใส่ Gemini API Key ที่ขอได้ฟรีจาก https://aistudio.google.com
3. กด "ถ่ายรูปอาหาร"

> ห้าม commit API Key ลงในโค้ด แอปนี้ไม่ได้ฝังคีย์ไว้ในไฟล์ ผู้ใช้แต่ละคนใส่คีย์ของตัวเอง

แคลอรี่ที่ AI ประเมินจากรูปเป็นค่าประมาณเท่านั้น
